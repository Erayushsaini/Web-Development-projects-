Full-Stack Roadmap — Notes

Reference page. Click any topic to check it off.
Already known: HTML, CSS, JavaScript, Node.js, Express, EJS, REST APIs, SQL — phases below build on these rather than repeating them.

0. Web Fundamentals

  • Client vs server, request/response
  • HTTP, HTTPS, DNS, IP address, domain, ports, TCP/IP
  • HTTP methods — GET, POST, PUT, PATCH, DELETE
  • Status codes — 2xx, 3xx, 4xx, 5xx
  • Headers, cookies, sessions, CORS, SSL/TLS basics

1. HTML (advanced)

  • Semantic HTML — header, nav, main, section, article, footer
  • Accessibility & ARIA
  • SEO fundamentals, meta tags, Open Graph
  • Forms, input types, validation
  • Structured data basics

2. CSS

  • Selectors, specificity, box model, positioning
  • Flexbox & Grid mastery
  • Responsive design — media queries, mobile-first, fluid layouts
  • CSS variables, transitions, animations, transforms
  • Pseudo-elements/classes, container queries
  • One styling ecosystem — Tailwind, CSS Modules, or Sass

3. JavaScript ⭐⭐⭐

  • Core: variables, scope, hoisting, closures, objects, arrays, strings
  • Modern JS — destructuring, spread/rest, optional chaining, nullish coalescing, modules
  • Higher-order functions, callbacks, IIFE, pure functions
  • Async JS — callbacks → promises → async/await → event loop
  • Promise.all, allSettled, race, any
  • Runtime internals — call stack, web APIs, micro/macrotask queues

4. Browser JavaScript

  • DOM tree, selecting/creating/removing elements
  • Event listeners, bubbling, capturing, delegation
  • localStorage, sessionStorage, cookies
  • Fetch API, URL API, History API, FormData, File API
  • WebSocket basics

5. Git & GitHub

  • init, clone, add, commit, push, pull, fetch
  • merge, rebase, branch, checkout, switch, stash, reset, revert
  • Pull requests, issues, branching strategy, semantic commits, code review

6. React ⭐⭐⭐

  • Components, JSX, props, state, events
  • Conditional rendering, lists & keys, forms
  • useState, useEffect, useContext, useRef, useMemo, useCallback, useReducer
  • Know when not to use each hook

7. Advanced React

  • Component architecture — pages → features → components → reusable UI
  • Container/presentational pattern, composition, props drilling
  • Custom hooks
  • React Router — nested, dynamic & protected routes, params, query params

8. State Management

  • useState/useContext for small apps
  • Redux Toolkit — store, slice, action, reducer, dispatch
  • RTK Query, or Zustand as an alternative
  • Server state vs client state (cart UI = client, product data = server)

9. TypeScript ⭐⭐⭐

  • Types, interfaces, type aliases, unions, intersections
  • Generics, enums, tuples, type narrowing, utility types
  • keyof, typeof, type guards, function types, classes, modules
  • Apply across React + Node + Express

10. Node.js (deeper) ⭐⭐⭐

  • CommonJS vs ES Modules, package.json, npm/npx
  • Environment variables, file system, streams, buffers
  • Events, EventEmitter, HTTP module
  • Node architecture — single thread, event loop, non-blocking I/O

11. Express.js (production-level) ⭐⭐⭐

  • Routing, middleware, controllers, error handling
  • Move from route-handler-does-everything to route → middleware → controller → service → repository → database

12. Backend Architecture

  • MVC vs layered architecture (routes → controllers → services → repositories → DB)
  • Separation of concerns, modular architecture, reusable services
  • Centralized error handling, configuration management

13. REST API (production design) ⭐⭐⭐

  • Resource naming, HTTP semantics, status codes
  • Pagination, filtering, sorting, searching, query params
  • API versioning, consistent error responses, validation

14. Authentication & Authorization ⭐⭐⭐

  • Registration, login, logout, password hashing
  • Sessions vs JWT — access tokens, refresh tokens
  • Email verification, password reset
  • Role-based access control — customer / admin / seller / moderator

15. Security ⭐⭐⭐

  • HTTPS, CORS, CSRF, XSS, SQL/NoSQL injection
  • Rate limiting, brute-force protection, secure cookies
  • HTTP security headers, input validation, output sanitization
  • Secrets management, OWASP Top 10

16. Validation

  • Zod, Joi, or express-validator
  • Frontend validation → backend validation → DB constraints (always validate on the backend too)

17. SQL (deeper) ⭐⭐⭐

  • Primary/foreign keys, constraints, JOINs, subqueries, CTEs, views
  • Transactions, indexes, composite indexes
  • Normalization/denormalization, ACID, isolation levels, query optimization
  • Go deep on one database — PostgreSQL recommended

18. MongoDB ⭐⭐⭐

  • Database → collection → document → field
  • CRUD, embedded documents vs references, indexes, aggregation, transactions
  • Schema design, MongoDB Atlas
  • Mongoose — schema, model, middleware, validation, population

19. SQL vs MongoDB

  • SQL — users, orders, products, payments, invoices, relationships
  • MongoDB — flexible/catalog-like data, rapidly changing schemas
  • Know both relational and document models rather than picking one by default

20. ORM / ODM

  • Prisma or Drizzle for SQL
  • Mongoose for MongoDB
  • Understand what the tool does underneath — don't treat it as magic

21. Caching ⭐⭐

  • Redis basics, TTL, sessions, rate limiting
  • Cache-check-before-DB pattern, cache invalidation, pub/sub basics

22. File Uploads

  • Multipart/form-data, file uploads, image validation/resizing/compression
  • Object storage — AWS S3 or Cloudinary
  • Product → images → object storage → DB stores the URL

23. Payments ⭐⭐⭐

  • Cart → checkout → payment gateway → confirmation → order creation
  • Payment intents, webhooks, idempotency, refunds, failed payments
  • Backend must verify payment state — never trust the frontend alone

24. Email & Notifications

  • Transactional email — verification, password reset, order confirmation, shipping
  • SMTP / email APIs, tied into background jobs

25. Background Jobs & Queues ⭐⭐⭐

  • Queue → worker → background task pattern
  • Retries, delayed jobs, failed jobs, idempotency
  • Redis + BullMQ
  • Example: order placed → API responds fast → queue handles email/invoice/analytics

26. WebSockets

  • HTTP request/response vs persistent WebSocket connection
  • Use cases — chat, notifications, live order tracking, dashboards
  • Socket.IO

27. Testing ⭐⭐⭐

  • Unit testing (individual functions)
  • Integration testing (API + database)
  • End-to-end testing (browser → frontend → backend → DB)
  • Tools — Vitest/Jest, Supertest, Playwright

28. API Documentation

  • OpenAPI / Swagger
  • Document request/response shapes for every endpoint

29. Logging & Monitoring

  • Structured logging, error logging, request logging
  • Health checks (GET /health)
  • Winston/Pino, Sentry, application metrics

30. Performance Optimization ⭐⭐⭐

  • Frontend — lazy loading, code splitting, image optimization, memoization, virtualization, CDN
  • Backend — indexes, query optimization, caching, compression, pagination, connection pooling, rate limiting

31. Next.js

  • File-based routing, server vs client components
  • SSR, static generation, dynamic rendering, route handlers, middleware
  • Understand both React+Express and Next.js — not a required replacement

32. DevOps — Linux ⭐⭐⭐

  • cd, ls, pwd, mkdir, rm, cp, mv, cat, grep, chmod, ps, kill
  • Processes, environment variables, ports, SSH, logs

33. Docker ⭐⭐⭐

  • Dockerfile, image, container, volume, network
  • Docker Compose — frontend + backend + database + Redis containers together

34. CI/CD

  • Push → CI pipeline → run tests → build → deploy
  • GitHub Actions, automated testing, build/deploy pipelines, secrets

35. Cloud

  • Go deep on one provider — e.g. AWS: EC2, S3, RDS, CloudFront, IAM, VPC, load balancer basics
  • Also know modern platforms — Vercel, Render, Railway

36. System Design ⭐⭐⭐

  • Scalability, availability, reliability, latency, throughput, bottlenecks
  • Client → CDN → load balancer → app servers → cache → database
  • Horizontal/vertical scaling, DB replication, sharding basics
  • Caching, message queues, microservices vs modular monolith
  • Start with a strong modular monolith — not microservices.

37. Advanced Ecommerce Architecture

React frontend → Express API → (auth / product / order services) → PostgreSQL → Redis, plus payment gateway + webhooks, object storage for images, a queue for background workers, and an email service for notifications.

What the ecommerce project should contain

  • Customer: registration, login, email verification, forgot password, profile, addresses, wishlist, cart, search/filter/sort, reviews & ratings, coupons, checkout, payments, orders, order tracking, returns, refunds, notifications
  • Admin: dashboard, product/category management, inventory, orders, users, coupons, reviews, sales & revenue analytics, reports
  • Advanced: search, recommendations, Redis caching, background jobs, payment webhooks, image storage, rate limiting, audit logs, API docs, testing, monitoring, Docker, CI/CD, deployment

Suggested project progression

  • 1. Vanilla JS — expense tracker (HTML/CSS/JS/DOM/localStorage)
  • 2. REST API — task management API (Node/Express/SQL/auth/validation)
  • 3. React — movie/product dashboard (React Router, API integration, state, forms)
  • 4. Full stack — blog/social platform (React + Express + PostgreSQL: auth, CRUD, images, comments, likes, pagination, search)
  • 5. Advanced — ecommerce (React + TypeScript + Node + Express + PostgreSQL + MongoDB where useful + Redis + payments + object storage + Docker + testing + CI/CD + cloud)
